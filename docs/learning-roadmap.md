# 每日 1–2 小时的渐进路线

每次约 20 分钟阅读/手推、40–60 分钟实现、20 分钟测试、10 分钟研究日志。
按交付验收推进，不以日历强制跳过理解步骤。

| 阶段 | 具体任务（每项一到两次学习） | 完成证据 |
| --- | --- | --- |
| 1 | 安装、运行扩散；手推首末行；用 NumPy 复核 2 单元矩阵 | 命令、推导、单元测试 |
| 2 | 20/40/80 网格误差表；Matplotlib 双对数图；解释二阶误差 | 图、斜率与守恒记录 |
| 3 | Python 函数/异常/文件 IO；pandas 读小型结果表；SciPy 交叉求解 | 非法输入与独立解对比 |
| 4 | 加入 Poiseuille 或非零边界扩散，不重复现有逻辑 | 解析剖面与边界测试 |
| 5 | 一维对流扩散：Upwind/Central、Peclet 数、稳态到瞬态 | 有界性、守恒、时间与空间收敛 |
| 6 | TVD/限制器，再压力速度耦合与二维不可压 Navier–Stokes | 小型基准与网格敏感性 |
| C++ 并行学习线 | vector/array、reference/pointer/const、RAII/class、文件和网格结构 | 独立编译、调试、数值通量单测 |
| 燃烧线 | 运行 0D；加密采样、收紧积分容差；温度/压力/phi 扫描 | 延迟定义与敏感性报告 |
| 论文线 | 补齐 emu 原文、DOI、目标图表；列未知条件；确认指标 | 锁定单一复现目标后才编码 |
| CFD 线 | 核实 OpenFOAM v2606；cavity 后 pitzDaily；记录运行预算 | checkMesh、守恒、剖面和网格对比 |

近期优先顺序：扩散推导与验证 → 论文资料确认 → 0D 敏感性 → cavity。
Fluent、TVC、压气机与 CFD–surrogate 耦合按 research/README.md 里程碑逐步开展。
不在第一轮实现全部路线，不默认 HPC/GPU 可用。
