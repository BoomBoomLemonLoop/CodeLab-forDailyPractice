# 开发指南

1. 阅读 AGENTS.md、相关案例与 `git status`；为一个明确问题建分支。
2. 手推模型与单位，写下预期结果；用最小网格/数据实现。
3. 运行案例、检查解析解/守恒/收敛，解释失败原因后再修改。
4. `python -m pytest`、`python -m ruff check .`、`python -m ruff format --check .`。
5. 用清晰目的分步提交并开 PR；未经审核不合并。

安装见根 README。依赖版本范围服务开发兼容性，具体一次运行必须保存
`python --version`、`python -m pip freeze`、OS 与 Git commit，不能将范围当锁定环境。
本轮 Windows 实测环境见验收记录；CI 覆盖 Python 3.11/3.12，其他版本不作已测试声明。
脚本从仓库根目录运行。参数输入验证先于重计算。随机算法显式传种子，并记录库版本。

`src/codelab` 当前仅作可安装包，不提前堆积误差/绘图工具。
某函数在第二个实际案例出现稳定复用后，再迁入共享模块并维护其测试。
案例脚本避免 import 时执行计算。Notebook 用于探索，稳定逻辑应落地到脚本和测试。

新增昂贵或外部软件测试标记 `integration`，默认排除；手动启用时记录 skip 与失败。
不得删除失败的有效测试。普通 CI 不运行 CFD。

提交前逐文件检查 `git diff --cached`，确认无密钥、原始受限数据、大型二进制或虚拟环境。
小型最终结果必须附命令、参数、来源和解释；中间产物使用 `outputs/` 或 `results/intermediate/`。
原始外部数据使用 `data/raw/`（忽略），确需共享时使用获授权的小型 reference 数据并记录哈希。

AI 可以辅助实现，但每个提交应能由研究者解释离散公式、边界条件、复杂度和测试依据。
不清楚的论文条件记录为 unknown，禁止自动补成确定事实。
