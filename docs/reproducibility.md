# 可复现与可信计算

本仓库采用以下操作性定义（不同学科可能用相反术语，因此报告必须重述定义）：

- Repeatable / 可重复：同一团队、相同代码/环境/输入重复运行，结果在规定数值容差内一致。
- Reproducible / 可复现：另一研究者利用公开或获授权的材料重建环境和流程，得到可比较结果。
- Verification / 数值验证：是否正确求解所声明的数学模型，包括实现测试、解析解、
  manufactured solution、守恒、迭代/时间/空间收敛。
- Validation / 物理验证：模型是否足以描述目标现实工况，需独立实验或合适物理参考与不确定度。
  与另一程序对齐属于交叉比较，不能自动替代实验验证。

状态词 Validated 必须写明比较对象和范围；解析解比对记为 Tested + analytical verification，
不宣称物理 Validated。程序可运行只是 Implemented 的必要检查之一，不是论文复现成功。

## 每次结果的最小证据

记录研究问题、方程、单位、边界/初始条件、机理/湍流模型、离散格式、网格、时间步、
求解器容差、随机种子（确定性案例写“不适用”）、OS、依赖精确版本、Git commit 和命令。
标注数据下载日期、DOI/稳定 URL、许可、提取脚本与 SHA256；图像数字化须记录标定和误差。
机理文件亦应记录版本和哈希，机理名称相同不保证内容不变。

## 比较指标与不确定性

对非零参考量使用 `|y-y_ref|/|y_ref|`；近零参考改用有物理单位的绝对容差，
或预先定义的尺度归一化误差。曲线比较明确采样/插值方式、区间和聚合范数。
±5% 只是论文复现的初步候选目标，应按指标、实验误差与提取误差逐项决定，不事后调整阈值。

区分离散误差、迭代误差、输入/测量不确定性、模型形式误差与统计波动。
至少三套网格/时间步先识别渐近区，再估计阶数；残差下降不等于网格无关或物理准确。
随机模型用多个种子检查波动；测试集与调参数据隔离。报告失败、未复现点和未知条件。
