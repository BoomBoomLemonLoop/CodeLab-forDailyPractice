## 每次活动记录格式（尚无实例）

```text
日期 / 任务 ID / 主题：
教材或资料：版次、实际阅读范围及材料 ID/链接，未知项注明
实际完成：推导/用户编写代码及路径；无代码就写无，区分用户实现与参考代码
检查证据：实际命令、环境、测试/验证结果与解释；未运行写未运行
尚未解决：概念疑问、失败、假设或数值局限
下一步：一个具体建议
成果链接：任务记录、笔记、commit/PR（如有）
```
