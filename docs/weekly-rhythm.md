# 每日 60–120 分钟的弹性节奏

以学习结果推进，不固定日期、不欠“补课债”。毕业论文压力大时保留 Cantera 主线与一次 CFD 学习即可。

| 可交换时段 | 方向 | 一次任务的上限 |
| --- | --- | --- |
| A1 | Turns → Cantera | 一个状态/热化学问题及量纲检查 |
| B1 | Anderson 第 7 章 | 一个喷管函数的推导与输入输出设计 |
| A2 | Turns → Cantera | 一个反应器假设或点火判据检查 |
| C1 | Moukalled / CFDPython | 一个控制体通量、数值算子或测试；必要时读 OpenFOAM 字典 |
| A3 | Turns → Cantera | 一个参数影响或定量对比 |
| B2 | Anderson 第 7 章 | 检查一步预测校正或修复一个边界问题 |
| 可选 | 整理/休息 | 总结证据，不新开一整套练习 |

60 分钟版本：10 分钟理论 → 30 分钟自己写代码 → 15 分钟检查 → 5 分钟记录。
120 分钟版本：20 分钟理论 → 60 分钟自己写代码 → 25 分钟检查 → 15 分钟记录/提交。
每次只选择一条可解释、可验收的任务。超过时间时记录停点、失败和下一步，不硬凑“完成”。

可能的进展是状态/组成 → 平衡约束 → 0D 反应器 → 小型参数敏感性；
喷管则是方程/几何 → 预测校正一步 → 边界和收敛 → 后续守恒形式比较。
这些是候选里程碑，不是自动创建的任务或四周完成承诺。

开始时查 [study-map.md](study-map.md) 与 [任务记录](study-tasks.md)。
Codex 先提供问题、必要假设、提示和验证路线，由学习者实现核心步骤；
结束时检查代码、解释错误、记录实际测试并提交到对应案例。
