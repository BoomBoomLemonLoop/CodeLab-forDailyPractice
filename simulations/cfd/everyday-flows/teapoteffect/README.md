# EVF-001 研究阶段存档

本页记录截至 2026-11-24 的研究状态与建议上传范围。当前计算是探索性数值工作，不是实验验证，也不构成已验证的 teapot effect 机理。

## 已完成

- **G0/G1 几何与运动学**：当前源代码、SI 参数、测试和结果见 [G0/G1 工程](EVF001-g0-g1-v3/README.md)。**10°/s 与 5°/s 是两个独立物理参数工况，不是新旧版本替换**：10°/s 参数和几何历史位于 `EVF001-g0-g1-v3/parameters.json` 及相应历史 CSV；5°/s 参数、代码和对照结果位于 `EVF001-g0-g1-v3/artifacts/angular_rate_5deg_s/`。5°/s 对照没有减半入口速度或流量，也不是流场模拟。
- **G2 入口截面模型**：源代码为 `EVF001-g0-g1-v3/g2_momentum.py`，参数及推导、假设和数值检查记录在 [G2/G3 阶段记录](EVF001-g0-g1-v3/G2_G3_PROGRESS.md)；小型速度场、验证 JSON 和图表位于 `EVF001-g0-g1-v3/artifacts/g2_momentum/`。模型在真实圆角截面的液相区域离散求解 `-∇²ψ=1`，使用无滑移固壁、顶部零剪切并按假设的 `Q=10 mL/s` 归一化。它是局部、稳态截面近似，不包含沿程发展、空气切向剪切或由倾倒动态求得的入口流量；10 mL/s 不是实测值。
- **G3 固定姿态三维 VOF**：代码、OpenFOAM 配置、工况、阶段结果和运行步骤分别见 [G3 源码与案例](EVF001-g0-g1-v3/g3_fixed/)、[非稳态运行说明](EVF001-g0-g1-v3/g3_fixed/TRANSIENT_RUNBOOK.md) 和 [结果报告](EVF001-g0-g1-v3/g3_fixed/G3_TRANSIENT_RESULTS.md)。两个案例固定姿态、固定重力和固定入口，不使用动态网格或倾倒角速度历史。
  - Case 1：已计算并分析至 **40 ms**；观察到出口圆角下侧附壁。尚未确认准稳态或稳定脱离位置。
  - Case 2：正式阶段观察按 **25 ms** 结果记录；该时刻仍处于出流形成阶段，尚未完成充分发展的流动分析。后来 `window2` 求解及重构日志均正常结束于 50 ms，但后续场未纳入本阶段物理结论。

## 初步观察、待检验假设与未完成工作

- Case 1 的圆角下侧湿润是初步流动现象，不等于已验证的 teapot effect 机理。Case 2 的短时观察也不足以确认充分发展或稳定脱离。
- “倾倒角速度仍过大”或“较快倾倒促进附壁”均为**待检验假设**，不是当前结论。5°/s 仅完成 G0/G1 几何时间重参数化，尚无与之关联的独立 G2/G3 流场模拟。
- 网格与时间步独立性、物理/实验验证、入口模型敏感性、准稳态判定及可靠脱离位置识别均尚未完成。固定姿态流场计算不能等同于完整动态倾倒模拟。
- **Case 2 存档一致性提醒**：首段 `log.interFoam` 正常结束于 25 ms；后续 `log.interFoam.window2` 在 50 ms 有 `End`，`log.reconstructPar.window2` 重构至 50 ms 并正常结束，运行记录为退出码 0。另一方面，`log_statistics.json` 是后续窗口运行前生成、仅统计至 25 ms；`CASE_STATUS.json`、指标和数值审计文件的更新时间早于后续窗口，部分记录至 30 ms。30 ms 汇总与 35–50 ms 场/重构结果均与正式 25 ms 报告口径分开保存；后续场尚未在本阶段重新分析，不能据此扩展物理结论或判定充分发展。所有原始资料均保留。
