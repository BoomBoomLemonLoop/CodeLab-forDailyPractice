## 1. 研究问题与固定条件

研究给定入口速度和液相分布时，固定三维倒棱锥圆角壶嘴上是否出现出口转向、下表面附壁、
周向展宽和脱离。最终证据必须来自真实三维两相求解与数值敏感性分析，而非几何动画。

- G0/G1 保留作为几何、两组出水姿态和覆盖范围的来源，只提取事件 B 的快照。
- G2 生成每个 Case **时间不变**的入口 alpha、速度剖面和通量。
- G3 使用固定 STL、静止壁面、静态计算网格、常量重力、恒定入口条件。
- G3 的模拟时间记为 t_CFD，只描述固定边界下的启动及流动演化；不继承 3 s/1.5 s 倾倒时钟。
- 不模拟完整水壶，不设运动轴，不重放倾倒，不用动态网格或旋转源项，也不生成新的倾倒动画。
- 固定边界并不要求稳态求解。采用非稳态 interFoam，让液面和接触区自由演化。

## 3. G2-A：把覆盖范围映射为液相区域

对每组快照，在 s=s_in 取实际内壁轮廓 w_wall(y)，令
`w_fs=(H−s_in sinβ)/cosβ`。入口水相区域为

`Omega_l = {(y,w): w_wall(y) <= w <= w_fs}`，并限制在实际开放截面内。

这给出整个液相面积，不是将湿周乘以假定 0.7 mm 膜厚。
入口所有真实流体面分为液体进料区及剩余空气区；不能让水通过固体厚度或外壁一侧进入。
对切过界面的网格面，应计算面覆盖分数 alpha_f，不能仅凭面心二值判断后直接宣称通量守恒。
尽可能使入口网格与界面/固壁分区相容；若使用分数面，同时积分 alpha·U，避免独立平均 alpha 和 U 造成通量偏差。

G2 输出计划：`inlet_geometry.vtp`、面心/面积/法向、alpha_f、U_f、通量表、源参数和坐标变换、输入来源级别。
最终边界数据应按实际 CFD patch 面生成；仅在 Python 规则网格上满足积分还不算 CFD 入口验收。

## 4. G2-B：速度来源与剖面

当前文件检索没有找到可直接复用的已实现速度求解器或已验证速度数据。
已有任务书只给出：`U≈C_d sqrt(2g Delta_h_eff)` 的候选估算、10 mL/s 教学流量和横向抛物线示意。
因此不把“我们已建立的速度模型”写成已求解事实；保留有效水头公式作为可替换的**假设幅值模型**，
其 Delta_h_eff、C_d、损失定义和速度含义必须记录。Delta_h_eff 不能直接取 G0 的 H 或几何交线推进速度。

为使探索计划可执行，允许先使用旧记录中的 **Q_ref=10 mL/s=1e−5 m³/s** 作为明确的假设进料量，
不是实测或真实预测。这只确定积分幅值；在上述入口，名义 U_mean=Q/A 分别约 0.28334 和 0.05154 m/s。
该固定 Q 基准不能同时宣称两组速度相同。随后可扫描 Q_ref 的 0.5、1、2 倍；若获得明确已有速度模型文件，
优先保存其公式、参数、版本和量纲后替换幅值，仍需保持以下剖面与积分检查。

### 首选的局部已发展剖面近似

在每个固定液相截面 Omega_l 上解二维轴向动量问题：

`−mu_l Laplacian_perp u = G`, `G=−dp/ds+rho_l*g_s > 0`。

固壁 `u=0`；自由界面先取切向零应力 `du/dn=0`，忽略空气切向应力。先解单位驱动力的形状 psi，
再按 `u=Q_ref psi / integral_Omega_l psi dA` 归一化，并记录对应 G 和隐含压力梯度。
等价先给定 U_mean，令 Q_ref=U_mean A；不能同时任意规定互不相容的 Q、平均速度和压力差。
在均匀深度平板薄层极限，数值解应恢复 `u=G(2hn−n²)/(2mu_l)` 及每单位宽度流量 `G h³/(3mu_l)`。
这是测试基准，不把真实 V 形截面套成均匀薄膜。

该模型只代表**假想局部直且等截面通道的层流、单向、已发展近似**。
真实壶嘴三角面沿程变化，局部截面解不能证明整个入口流动已充分发展；横向抛物线更不能自动获得这一名称。
检查 Re（注明采用 4A/P 的水力直径或其他尺度）、入口发展长度、自由面变化和气液剪切影响；
若此近似不适用或结果对入口剖面敏感，使用独立固定几何的两相前驱计算，输出稳定的截面分布，
再冻结映射为主 Case 入口。前驱流场也不得重放倾倒过程。
速度三分量在纯轴向近似下为 `(u,0,0)`；前驱模型可提供横向分量，但必须注明来源。

### G2 验收（计划阈值，不是已获得结果）

- 水相区域不穿墙，0<=alpha<=1；固壁无滑移，界面应力边界与模型一致；轴向通量为正。
- Python 剖面积分 Q 与目标相对差 <=0.1%；截面网格至少两级细化，Q、U_max 与剖面误差记录。
- 映射至 CFD patch 后，按同一离散通量重算 `Q_in=−sum(alphaPhi_f)`（外法向约定）。
  实际 alpha 输运通量优先于简单 alpha_f*phi_f；若二者不同须分别记录。入口误差目标 <=0.5%。
- 如需离散幅值再归一化，记录修正系数与前后 Q；不掩盖大面积覆盖错误。
- 重力及 U 在局部/世界坐标往返一致，SI 单位明确；Q、rho Q、U_mean、U_max、Re 写入报告。
- 不能以稳态局部入口剖面测试代替 G3 的全域质量守恒检查。

## 5. G3：独立固定几何三维 VOF

未来路径初定 `EVF001-g2-g3-fixed/cases/case1_fixed/` 与 `case2_fixed/`。
这不是复制另一套 G0/G1；由固定交接清单引用现有几何，保留哈希，网格处理副本单独存放。
不覆盖 `kettle-spout-vof-openfoam-v2606`、draft、v3 或此前成功的任何 OpenFOAM Case。

计算域覆盖入口至出口、包边、外壁、周边空气及脱离后足够的下游空间。
内壁/包边/外壁划分独立 patch 或几何分区，材料参数相同，便于统计。
外部空气域边界不能贴住液膜或脱离射流；做域尺寸、下游/侧方开边界和入口位置敏感性。
固体在入口平面处的裁切/封口与入口流体窗口分开，网格不得把进料口封成墙。

### 方程与边界计划

水–空气不可压、等温 VOF，包含两相黏性、重力、表面张力、静止无滑移固壁及接触角。
先作层流探索并检查尺度适用性；若出现未解析湍动，不能仅靠层流解宣布机理已验证。
探索性物性先统一采用 rho_l=998 kg/m³、nu_l=1e−6 m²/s，rho_g=1.2 kg/m³、nu_g=1.5e−5 m²/s，
sigma=0.072 N/m；它们是统一假设输入，温度/材料实测匹配另行校准。
首组静态接触角统一暂取 60°（示例，不称为材料测量）；接触角定义、所用相和字典实现必须核对。

| 区域 | alpha.water | U | 压力处理 |
| --- | --- | --- | --- |
| 水相进料窗口 | 固定液相覆盖/面分数 | 固定 G2 非均匀剖面 | 与规定通量相容的压力梯度条件，避免同时强加任意入口总压 |
| 上游剩余空气开口 | 出流外推、回流为空气 | 压力驱动允许通气 | 大气参考压力及 p_rgh 转换 |
| 其他远场开边界 | 出流外推、回流为空气 | 允许流出及空气补入 | 大气参考压力，考虑 p_rgh 的重力基准 |
| 固体 | 接触角边界 | noSlip | 与静壁通量相容的压力条件 |

候选实现包括 pressureInletOutletVelocity、prghTotalPressure 和 fixedFluxPressure，
但具体组合、alpha 接触角类型及字段语法必须依据本机 **OpenFOAM.com v2606** 教程/源码确认。

## 6. 守恒、充分发展与停止判据

`V_l(t)=sum(alpha_i V_i)`，边界外向液相通量 `F=sum_boundary alphaPhi_f`。
检查 `V_l(t)-V_l(0)+integral_0^t F dt=0`，包括全部开边界和侧向损失，不只比较一个入口/出口 patch。
另列指定出口截面 Q、远场离域 Q 和侧向出流，避免把越过截面与离开计算域混成同一个量。
累计相对残差以 `max(V_l(0), integral Q_in dt, small_scale)` 归一化，初始为零时不能除零。
第一轮目标累计误差 <1%；误差随网格/时间步是否降低同样需报告。

以局部流经时间 T_flow=L_local/U_mean 设计观察窗，不能沿用 3 秒。
建议至少比较 3 个连续窗口、每窗不少于 5 T_flow 的 Q_out、V_l、外壁湿润面积及脱离位置。
准稳态候选标准：窗口均值变化 <2%、无持续液体堆积、质量平衡通过；相对变化分母接近零时用预先定义的绝对尺度。
若持续滴落或周期性脱离，则报告统计稳定的非稳态均值、RMS、周期和分布，不能强迫称为稳态。
达到资源上限仍有趋势或未覆盖足够周期时标记未收敛，不据此排除/确认 Teapot Effect。

## 7. 可分析输出与 Teapot Effect 判据

- alpha.water、U 的三分量、压力、液相通量、体积分数有界性及时间步/Co 日志。
- 内壁、包边和外壁分别统计；alpha=0.5 等值面仅作近似自由界面显示。
- 外壁润湿面积：预先指定“出口包边下游的外壁 ROI”，用壁邻单元/重构液相占据度加权面面积。
  对 0.1/0.5/0.9 阈值、壁邻层厚度和网格做敏感性；不把该估计称为精确接触线。
- 附壁长度：从包边外侧接缝沿外壁表面测量，与主出流连通的持续湿润区最远弧长；孤立飞滴另计。
- 脱离位置：结合连通性、壁邻液相、界面与速度方向识别离壁位置/角度，并给时间变化和阈值不确定性。
- 周向展宽：固定轴向/弧长站位的液相横向跨度及 U_y；保持站位定义相同。
- 附壁分流可用外壁邻近控制面液相通量占总供水的比例，和主射流/侧向流失共同核算。

只有当启动后供给的液体持续绕过包边并沿下表面形成连通附着区，且现象通过质量守恒、
网格/时间步/域与初始条件检查，才称为“本模型条件下观察到附壁/Teapot Effect”。
单帧贴壁、初始人为填水、弥散 alpha 薄层或孤立滴撞壁都不足以支持该结论。
数值结果不等于实物实验 validation；没有得到预期现象也须如实报告。

## 8. 对比矩阵与归因

先固定材料、接触角、R5/R0.6、壁厚与物性，比较两组来源状态；两组姿态导致重力分量也不同，
这一首轮对比是“局部出水条件组合”的比较，不能将全部差异归因于水位或几何覆盖。

随后在同一固定姿态/重力下：

1. 固定覆盖和接触角，改变速度幅值（或 Q），并报告另一者的随动变化。
2. 固定平均液相速度与接触角，改变覆盖，记录 Q=U_mean A 的变化；补充固定 Q 的覆盖对比。
   面积改变时不声称同时固定 Q 和 U_mean。
3. 固定覆盖和速度，仅改变接触角（例如 60°/90°/110°，全部为假设材料扫描）。
4. 必要时交叉固定重力或比较相同覆盖/速度下的 25°与55°，区分姿态效应。

不在同一机制扫描中同时改变入口速度、覆盖、材料和圆角。
入口剖面类型、初始化、网格/时间步变化属于模型敏感性，须与物理控制变量分开记录。
