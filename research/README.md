# 原创研究路线（全部 Planned）

## Trapped Vortex Combustor

问题：个人计算资源能否识别小型涡喷 TVC 的可行冷流结构及主要代价？
顺序：简化冷流 → 驻涡/回流区 → 流体交换与停留时间分布 → 总压损失 →
Cantera 化学时间尺度 → 在基准与资源允许时反应 RANS。
每阶段分别报告网格敏感性、湍流模型不确定性和边界条件影响。
停留时间与点火延迟之比只能作为时间尺度分析，不能独自证明稳焰。

## Centrifugal Compressor

先收集有几何、边界和性能数据许可的可信基准，再建立项目。
候选问题：叶尖间隙泄漏、二次流与低动量输运、扩压器匹配、效率与稳定范围。
单工况稳态 RANS 不能独自确定真实失速/喘振边界。

## Surrogate Optimization

先 DOE 与小型回归，划分训练/验证/测试集，记录种子、尺度变换及数据泄漏检查。
随后 GP/Kriging、交叉验证、优化与 CFD 闭环；必须用独立 CFD 或基准评估推荐点，
不把训练误差当泛化能力。每个阶段完成问题—实现—计算—核查—解释后再扩展。
