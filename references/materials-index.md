# 本地学习资料索引与接入规则

2026-11-18 检查：整合前仓库没有 `materials/`；本轮仅建立以下本地空目录，
尚无实际资料可阅读。没有把目录名当作已经收到或读过教材的证据。
原始资料由根 `.gitignore` 的 `/materials/` 排除，不提交 Git。

```text
materials/
  textbooks/anderson/
  textbooks/moukalled/
  textbooks/turns/
  papers/
  courses/

  other/
```

新克隆不会带上这些忽略目录；需要时本地创建即可，不加入 .gitkeep 或原始资料。
此索引可提交，但只记录必要书目信息、相对路径和阅读范围，不抄录私人笔记、整段原文或敏感数据。
已知的学习目标来自用户陈述，见 [当前学习映射](../docs/study-map.md)；
GitHub 链接继续维护在 [收藏用途](starred-github.md)，不复制成另一份收藏清单。

## 用户要求整理新增资料时

1. 检查实际文件与本索引上次记录，比较相对路径、修改时间，必要时 SHA256，识别新增/变更。
2. 阅读能够访问的目录、摘要、相关章节及必要代码，记录确切范围；扫描件/OCR 不清楚应注明。
3. 提取主题、先修知识、版次和引用位置，区分原文事实、解释和推论。
4. 与 [知识关联](learning-map.md) 和当前任务比较，只在必要处更新映射。
5. 提出一个适合当前阶段的练习候选，由实际启动任务再创建代码，不批量生成答案。

## 实际资料记录

目前无条目。首次接入时使用以下字段，不预填虚构文献或完成状态：

```text
资料 ID / 标题 / 作者 / 年份 / 版次：
本地相对路径或稳定 URL / 上游 commit：
检查日期 / 文件修改时间 / SHA256（适用时）：
阅读状态：未检查 | 部分检查 | 无法访问（原因）
实际阅读范围：目录/摘要/章/页/图/公式或代码文件；PDF页码与印刷页码分别注明
主题 / 先修知识 / 与现有案例的关系：
许可与引用限制 / 尚不确定的事项：
下一步候选练习 / 任务或学习进度链接：
```

资料被修改后旧的阅读范围不自动适用于新版本，须重新核对有关内容。
读过指定章节不表示检查全书；读过源码不表示运行或验证过它。
