# 跨资料知识关联与适用边界

本页维护知识关联与先修关系；章节、代码路径、当前进度统一链接
[docs/study-map.md](../docs/study-map.md)，不建立第二份相同的章节表。
资料内容是否实际读过以 [materials-index.md](materials-index.md) 为准。
下列是学习组织建议，不是对尚未查阅教材原文的引用或已掌握能力的断言。

| 关联 | 先修/可迁移能力 | 必须保留的区别 |
| --- | --- | --- |
| Turns → Cantera → TVC 时间尺度 | 状态量与单位、化学计量、质量/能量收支、ODE、点火判据 | 平衡不含动力学时间；0D 均匀点火不包含混合、热损失、驻留时间分布与湍流稳焰 |
| Anderson → CFDPython | PDE、数组索引、边界、显式推进、误差与稳定性检查 | 准一维可压喷管与不可压 cavity 的方程/边界不同，不能直接套用同一求解器 |
| Moukalled → 已有扩散 → OpenFOAM | 控制体积分、面通量、离散矩阵、守恒与收敛 | 手写常系数一维扩散只验证特定算子，不证明多维网格/RANS 设置正确 |
| FVM 理论 → FVM2D/C++ 阅读 | 网格/面数据结构、vector/const/引用、编译调试与通量接口 | 能读调用链不等于已编译、复现或验证上游；记录来源与许可证 |
| 已验证案例 → 论文复现/代理优化 | 数据来源、独立测试、误差指标、不确定性与训练/验证分离 | 学习案例或训练拟合误差不等于论文复现成功或目标工况泛化有效 |

默认顺序：Cantera/毕业论文 → Anderson 当前章节 → Moukalled/OpenFOAM →
CFDPython/源码学习 → C++ → 代理与优化。根据论文需求、实际代码困难和学习证据调整，
不将其解释为六门都必须完成的课程，也不要求为了顺序停止当前章节。

新资料只有引入新的先修关系、方法或适用边界时才扩展本表；已覆盖主题直接链接原案例。
不因文件新增而自动重构目录。每日任务从一个具体问题出发，必要时做短诊断后再定范围。
